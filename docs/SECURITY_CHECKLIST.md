## القائمة

| # | البند | الحالة | التفصيل والأمر الحرفي |
|---|---|---|---|
| 1 | **فرض HTTPS** — TLS تلقائي + HSTS | ✅ + 🔲 | **✅** Caddy يحصل على شهادة Let's Encrypt ويجددها تلقائيًا (`deploy/Caddyfile.prod`) + ترويسة HSTS مضمّنة فيه · **🔲** تفعّل بالتركيب: `sudo cp deploy/Caddyfile.prod /etc/caddy/Caddyfile` ثم drop-in `Environment=DOMAIN=...` (deploy/README.md §8). تحقق: `curl -sI https://$DOMAIN/ \| grep -i strict-transport` |
| 2 | **حدود المعدل جاهزة** | ✅ | مدمجة في الكود (`src/lib/rate-limit.ts` — في الذاكرة): **دخول الأكواد 5 محاولات/دقيقة لكل IP** (`login:{ip}`, 5/60s) + **قفل مؤقت بعد 10 محاولات فاشلة لمدة 15 دقيقة** (`codefail:{ip}`) · كذلك: تجديد الجلسة 10/د · بحث حجز 5/د · إلغاء 5/د · التوفر 20/د · إنشاء حجز 10/ساعة. ملاحظة: العدادات في الذاكرة (تُصفّر عند إعادة التشغيل) — كافية لمقياس فندق واحد؛ إن ظهر إساءة عبر موزّع IP مستقبلي فقرار تدوير/تصعيد موثق |

| 4 | **أذونات القاعدة** | 🔲 | `sudo chown deploy:deploy /opt/cairo-hart/db && sudo chown deploy:deploy /opt/cairo-hart/db/custom.db && sudo chmod 750 /opt/cairo-hart/db /opt/cairo-hart && sudo chmod 640 /opt/cairo-hart/db/custom.db` · تحقق: `stat -c '%U:%G %a' /opt/cairo-hart/db/custom.db` |
| 5 | **تحديث الاعتماديات (محسوب)** | 👤 + ✅ | الجدول الشهري (MONITORING §4): مراجعة التحذيرات أولًا ثم تحديث محسوب: `cd /opt/cairo-hart && bun outdated` → `bun update next` (ونظائرها واحدة واحدة) → `bun test` + `bun run build` → `bash deploy/deploy.sh`. مراجعة الأمان: `bun pm audit` + تقرير AUDIT_REPORT (الأكثر إلحاحًا: **DEP-01 — ترقية next إلى ≥16.2.11** داخل نطاق `^16.1.1` الحالي بلا كسر متوقع، مع جولة CI). 👤 قرار المالك لتوقيت الترقية |
| 6 | **تدوير الأسرار عند تسريب** | 👤 | بطاقة RUNBOOK IC-3: إبطال الكود المسرب (يقتل جلساته فورًا) + مراجعة سجل التدقيق للفترة + توليد بديل. تدوير env عند أول مفتاح تجاري (RUNBOOK §3). 👤 التدريب الفعلي على البطاقة قبل الإطلاق قرار مالك/مشغل |
| 7 | **مراجعة أكواد نشطة/منتهية** | ✅ + 👤 | **✅** الاستعلام الإداري موجود (الإدارة → الطاقم والأكواد) + استعلام خادمي: `sudo -u deploy sqlite3 /opt/cairo-hart/db/custom.db "SELECT type,status,COUNT(*) FROM access_codes GROUP BY type,status;"` · 👤 تنفيذه شهريًا على المشغل (روتين RUNBOOK §2) |
| 8 | **نسخ خارج الموقع مفعّل** | 🔲 + 👤 | BACKUP_POLICY §7: تفعيل `RCLONE_REMOTE` في `/etc/cairo-hart/env` بعد `rclone config`. **🔲** التفعيل تقني عند التركيب · **👤** اختيار الوجهة السحابية قرار المالك (تكلفة/موقع) |
| 9 | **جدار ناري — 80/443 فقط** | 🔲 | `sudo ufw allow OpenSSH && sudo ufw allow 80/tcp && sudo ufw allow 443/tcp && sudo ufw enable && sudo ufw status verbose` · المنافذ 3000/3002/3004 محلية خلف البوابة (تحقق: `sudo ss -tlnp \| grep -E '3000\|3002\|3004'` — 3004 يظهر على 127.0.0.1 فقط) |

## طريقة الإغلاق الرسمية

1. انسخ هذا الجدول في مراجعة ما قبل الإطلاق (LAUNCH_PLAN قائمة الإقلاع).
2. لكل بند 🔲: نفّذ الأمر الحرفي وضع تاريخ التنفيذ.
3. لكل بند 👤: قرار المالك يُوثق بتاريخ (نصًا أو بريدًا محفوظًا).
4. **البوابة:** لا بند «حرج» يبقى مفتوحًا. البنود المؤجلة (مثل DEP-01 إن قرر المالك الترقية بعد الإطلاق) تُسجَّل بتاريخ قرار + أجل محدد — التأجيل المؤجل بلا أجل يُعد بندًا مفتوحًا.
