## 1. قواعد الاستخدام

1. **يُفتح البند فور الاكتشاف** — لحظة الإبلاغ عبر القناة، لا ينتظر الفتح مراجعة المساء (الاستثناء الوحيد: SEV-3 يجوز تأجيله إلى المراجعة المسائية). بنود SEV-1 تُفتح في الدقيقة وتُبلَّغ هاتفيًا وتوقف البرنامج (DOGFOOD_PLAN §4).
2. **لا يُحذف بند أبدًا، ولا يُعاد استخدام معرف.** التصحيح أو الترقية يحرّر الصف نفسه — المسح ليس مسارًا موجودًا في هذه القائمة.
3. **يُغلق البند بدليل فقط** (اختبار انحدار أخضر مذكور باسمه، أو دليل تشغيلي موثق داخل الصف) **أو يُؤجَّل بقرار** له صف مؤرَّخ في سجل القرارات اليومية (§4).
4. **الاختبار المرافق إلزامي** لكل بند SEV-1/SEV-2 في مسار مال/دومين (قائمة «مسار مال/دومين» في DOGFOOD_PLAN §4) — بند بلا اختبار مرافق **لا يُغلق مهما بدا الإصلاح ناجحًا** (AD-09).
5. **الحالات الأربع فقط:** مفتوح → قيد الإصلاح → مغلق-بدليل / مؤجل-بقرار. لا حالة خامسة ولا رجوع من «مغلق» إلا بفتح بند جديد بمعرف جديد يشير إلى القديم.
6. **التصنيف عند الشك من الأعلى:** إن لم يُحسم بين SEV-1 وSEV-2 فهو SEV-1 — قرار التخفيف لاحقًا يُسجَّل في عمود «القرار والمرجع»، لا يُصحَّح صامتًا.
7. **التأجيل ليس تجاهلًا:** كل بند «مؤجل-بقرار» يُراجَى إلزاميًا في كل مراجعة أسبوعية (يوم 7 ويوم 14) ويجدد قراره أو يُغلق أو يُصعَّد.
8. معايير خروج البرنامج تُقرأ من DOGFOOD_PLAN §7 — هذه القائمة **هي** مقياسها الثاني: صفر بند «مفتوح/قيد الإصلاح» في نهاية اليوم 14.

## 2. قالب البند (الأعمدة التسعة)

| العمود | القاعدة |
|---|---|
| **المعرف** | يتصاعد تسلسليًا: DF-001، DF-002، DF-003… (يُخصص DF-000 للمثال التوضيحي وحده) — لا يُعاد استخدام معرف أبدًا |
| **التاريخ** | تاريخ **الاكتشاف** بصيغة YYYY-MM-DD |
| **اليوم من التجربة** | D1…D14 (وD0 لما قبل الانطلاق) — يقابل جدول DOGFOOD_PLAN §3 |
| **الشاشة والمسار** | المنصة (ويب/جوال) + الوضع + الشاشة/الحوار + خطوات إعادة الخلل باختصار |
| **الوصف** | ما حدث فعلًا مقابل ما كان متوقعًا — بلا تشخيص مسبق للسبب |
| **التصنيف** | SEV-1 / SEV-2 / SEV-3 وفق جدول DOGFOOD_PLAN §4 |
| **الحالة** | مفتوح / قيد الإصلاح / مغلق-بدليل / مؤجل-بقرار (الحالات الأربع فقط — قاعدة §1-5) |
| **الاختبار المرافق** | اسم ملف اختبار الانحدار (مثل `tests/integration/xxx.test.ts`) — **إلزامي** لـ SEV-1/SEV-2 في مسار مال/دومين (يفشل قبل الإصلاح وينجح بعده) · «—» لما سواها |
| **القرار والمرجع** | آخر قرار + مرجعه (تاريخ/صف سجل القرارات §4) — مثل «استئناف بعد SEV-1 — قرار 2026-09-12» |
